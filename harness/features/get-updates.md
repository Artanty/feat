# get-updates

Docs: `back/docs/get-updates.md`; spec: `back/spec/get-updates.md`; code:
`back/features/get-updates/v1, v2/js-node/`.

Standardizes the ad-hoc `/get-updates` runtime-info endpoints as one vendored
feat feature (route slot): deploy identity from CI env rows, framework
detection (nest>express>fastify>koa>hapi), packages, filled slots, env
PRESENCE map (values never sent). v2 adds feat.json (catalog-aware). The
feature that drove the loader v2/v3 evolution (rename getupd→get-updates,
named slots). Consumers: stat, safe, tik.
